# PokéRogue 离线联机版 · 民间创意工坊

这里收集玩家给「PokéRogue 离线联机版」提的点子，并把其中做出来的变成可以随时开关的 mod。

## 这是什么

- **mod** 是一小包可装卸的新内容，比如几个新道具。它跟着游戏安装包一起发，不用另外下载。
- 在游戏里打开「合作模式 → Mod（民间创意工坊）」，能看到装了哪些 mod、是谁做的、点子是谁提的，每个都有开关。
- 开关记在你自己的设备上。**关掉不会坏存档**；再打开，之前拿到的 mod 道具还在。
- 每个 mod 写着自己在哪种玩法里生效：有的只在双人合作里，有的单人模式也能用。一个都不开的话，单人和合作都和原来完全一样。

游戏本体在这里下载（mod 已经在安装包里，默认是关的）：

- 手机版（安卓、iOS）：<https://github.com/1596941391qq/pokerogue-ios-android/releases>
- 电脑版（Windows、Mac）：<https://github.com/1596941391qq/pokerogue-desktop/releases>

## 我有个点子

不用会写代码。到本仓库的 **Issues → New issue → 提个点子**，照着表格填：

1. 点子叫什么
2. 具体效果，越具体越好（什么时候触发、数值多少、能用几次）
3. 你希望怎么署名

看到合适的会做成 mod，做的时候有拿不准的地方会在 issue 里问你。

没有 GitHub 账号也行，直接在 QQ 群里说：颠一群 1043163527，满了进颠二群 1046750108。群里提的点子一样会记下来，做出来一样署你的名。

## 我想自己做一个 mod

1. 看一遍 [Mod 格式和接口](docs/MOD-API.md)。想知道引擎是怎么接进游戏的，看 [engine/](engine/)（`EXT.md` 讲怎么给引擎加新的事件）。
2. 照着范例 [mods/better-coop-items](mods/better-coop-items/) 新建 `mods/你的-mod-id/`，放 `mod.json`、`mod.js`，再加一个 `README.md` 写清楚每样东西的效果；道具图标放 `icons/道具id.png`（最大 32×32）。
3. 跑一下自查：`node tools/build-mods.mjs . --check`
4. 提 Pull Request。会有人看代码、在游戏里实际试一遍，没问题就合并，跟着下一次安装包一起发。

几条规矩：

- mod 只通过接口干活，不直接改游戏内部的东西，这样游戏更新后不容易坏。
- 不联网、不收集任何信息、不碰玩家存档。
- 给玩家看的字用简体中文。
- 新道具的出现概率不要高过同品质的原版道具。
- 默认是关的，由玩家自己决定开不开。

## 署名

- 点子是谁提的，写进 mod 的 `credits`，游戏里的 mod 列表会显示。
- 代码是谁写的，写进 `author`。
- 在别人的 mod 上改，保留原来的署名，把自己加在后面。
