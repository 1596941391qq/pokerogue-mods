# 进阶（累积难度）v0.1

点子、规则表和原始实现：B 站 [Chess_大概是屑 & 深溟Ming](https://space.bilibili.com/358023819)（GitHub [Chess12333](https://github.com/Chess12333/pokerogue-desktop)）。
他们最早是直接改电脑版做出来的；这里照工坊接口（版本 3）重写了一遍，规则表没动，所以手机版也能用，随时能关。

## 这是什么

《杀戮尖塔》式的累积难度，0 到 10 级。选 N 级，第 1 到第 N 条规则同时生效。

- **单人模式和双人合作都能用**（这是第一个能在单人模式里生效的 mod）。
- **0 级和没开这个 mod 时完全一样。** mod 默认是关的。
- 等级跟着这一局的存档走：读档回来还是这一级；没开进阶时存的旧档读进来是 0 级。

## 什么时候能玩到

**11-20 版安装包（标签 pokerogue20261120）起自带**，更新到这一版就有：[电脑版下载](https://github.com/1596941391qq/pokerogue-desktop/releases/tag/pokerogue20261120)、[手机版下载](https://github.com/1596941391qq/pokerogue-ios-android/releases/tag/pokerogue20261120)。更早的安装包里没有这个 mod。

## 怎么用

1. 在 Mod 列表里打开「进阶（累积难度）」。电脑版：菜单「合作模式 → Mod（民间创意工坊）…」；手机版：标题画面左上角「联机」面板里的「Mod」按钮。
2. 开新游戏。到选宝可梦的界面时会先弹出一个列表，选这一局的进阶等级；列表最后一项「保持不变」（或按取消键）就是沿用上一次选的等级。
3. 战斗时右上角金钱下面有一个「进阶 N」的小标记，电脑上鼠标移上去能看到现在生效的规则（手机上在 Mod 列表里看）。读档界面的每个存档上也标着它的进阶等级。
4. 想中途改等级：打开 Mod 列表，在这个 mod 下面点别的等级。马上生效，也会记进存档。

## 十条规则

| 等级 | 名字 | 效果 |
|---|---|---|
| A1 | 迁徙之时 | 每次遇到野生宝可梦有 18% 的概率换成别的地区的；初始选择点数 10 → 8 |
| A2 | 资源短缺 | 换地区时的免费回复只回到最大 HP 的 60%（本来就高于 60% 的不变）；复活类道具（活力碎片、活力块、复活种子等）恢复的 HP 变为原来的 60% |
| A3 | 艰苦行动 | 打赢战斗和金钱道具拿到的钱减少 15%。商店价格不变 |
| A4 | 弱点击破 | 敌人用克制你的招式打你时，伤害再 +25% |
| A5 | 严格审核 | 队伍最多 5 只：开局选不了第 6 只；满 5 只时再抓到新的，要放走一只才能留下 |
| A6 | 断绝制图 | 奖励里不再出现「地图」，换地区时不能选目的地 |
| A7 | 稀缺 | 奖励里的高级道具（金色）出现概率从 48/1024 降到 30/1024，肉鸽道具（红色）从 12/1024 降到 6/1024，少掉的变成超级道具（蓝色） |
| A8 | 训练严苛 | 拿到的经验变为 80% |
| A9 | 墙立于此 | 所有首领的血条多一段 |
| A10 | 联合狩猎 | 第 20 层以后，每逢 5、15、25……层（5 的倍数里不是 10 的倍数的那些）也出首领 |

双人合作里：等级是整个房间这一局共用的，由房主在选宝可梦时选；A5 的「最多 5 只」是每人 5 只。

## 和原版（改电脑版的那一份）的差别

规则表一条没改，下面几处是照规则的本意做的，和原来那份代码的实际表现不一样：

- **A2**：原来那份的「回复打折」实际没有生效，这里生效了（只回到 60%）。
- **A3**：原来那份连商店价格一起降了 15%（价格和收入共用同一个基数），这里只降拿到的钱，价格不变。
- **选等级的列表**：原来按取消键会选到最后一项（10 级），这里最后一项是「保持不变」，按取消不会误选。
- **等级存在哪**：原来记在这台设备上、所有存档共用；这里每一局各存各的，存档界面能看到。
- **F8 快捷键**没有搬过来（手机上没有键盘），改等级统一在 Mod 列表里。
- 手机版在单人局里只能回到标题画面打开 Mod 列表（单人局里没有「联机」面板）。

## 已知的限制

- 这是新做的，十条规则都在游戏里逐条测过数值，但没有长时间玩过。遇到问题请到本仓库提 issue，写清楚第几级、第几层、发生了什么。
- A10 多出来的首领和原版首领一样有血条分段，A9 开着时再加一段。
