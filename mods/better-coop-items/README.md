# 更好的联机道具

点子：B 站 蟹堡星人。第一个可装卸 mod，也是写 mod 的范例。

四个只在双人合作里出现的携带道具。打完一波后的「5 选 2」奖励里有机会刷到，选中后给自己的一只宝可梦带上。
下面的「队友」指场上站在你旁边的那只宝可梦，不管它是谁的。

## 提出时的原话

- **气势纽带**（紫色品质）：携带该道具宝可梦的友方宝可梦在满HP时若被一击导致HP归零，则会保留1点HP而不进入昏厥状态，剩余的伤害由携带者承受，使用一次后道具本局失效。
- **讲究望远镜**（红色品质）：携带该道具的宝可梦对【集火】的目标造成的伤害×1.5倍，只能使用上场后使出的第一个招式。重新上场或重新获得道具时效果重置。
- **粉色香草**（金色品质）：携带该道具的宝可梦与友方宝可梦都陷入异常状态（中毒、剧毒、睡眠、麻痹、灼伤和冰冻）时会一起得到治愈，使用1次后消失。
- **共生孢子**（紫色品质）：携带该道具的宝可梦在获得能力变化时，友方宝可梦获得相同的能力变化。

## 做的时候是怎么理解的

**气势纽带**
- 只管招式打出来的伤害，天气、中毒、反伤这些不算。
- 「剩余的伤害」= 这一击的伤害减去队友实际掉的血。全部由携带者直接承受，可能把携带者打倒。
- 一局只发动一次，发动后道具还在身上，图标变灰。
- 同一回合里队友再挨第二下，就不是满 HP 了，不会再救。

**讲究望远镜**
- 「集火」用的是游戏里现成的判定：这回合两位玩家都用单体招式打同一个敌人。打全体的招式不算集火。
- 加成只给带着望远镜的那只，队友不加。
- 像讲究系列一样锁招：上场后用的第一个招式就是之后唯一能选的招式（PP 用完就只能挣扎）。换下再上场，或者重新拿到道具，重新算。
- 留在场上连打几波不算「重新上场」，锁会一直在，和能力等级跨波保留是一个道理。

**粉色香草**
- 两只都有异常状态的那一刻发动：有一只刚中状态时检查一次，每回合开始再检查一次（比如已经中毒的宝可梦换上场，和麻痹的队友凑到一起）。
- 两只的状态可以不一样。混乱、着迷这类不算异常状态。
- 发动后道具消失。

**共生孢子**
- 升和降都传，自己用招、被对手降、特性触发的都算。传的是实际生效的量（已经 +6 再升就没有可传的）。
- 传给队友的那一份不会再被传回来。两只都带孢子时，各自的变化各传一次就停。
- 队友那边按「直接改等级」处理，不会被白色烟雾之类的特性挡掉。

## 出现概率

按品质放进对应的奖励档位，权重不高于同档位的原版携带道具。
紫色档本身极少出现，所以气势纽带和共生孢子会非常稀有；金色的粉色香草相对最容易见到。
